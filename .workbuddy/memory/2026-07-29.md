## 样式回归：v1.1.23 的 class 重命名 bug（重要）
- 用户反馈：从 1.1.23 起存储系统样式变了，要求按 1.1.22 样式。
- 根因：v1.1.23 提交(3b0c8d9) 把 Storage.jsx 所有 `stg-` 前缀 class 全删了（如 `stg-card`→`card`、`stg-field-input`→`field-input`、按钮 `stg-btn`→`btn` 等），但 index.css **没有同步改名**（CSS 仍是 `stg-card`/`stg-field-input` 那套）。结果 JSX 引用的 `.card`/`.field` 等在 CSS 中不存在，表单卡片/输入框样式丢失（SelectField 因用 `.field-group`（本来无前缀）未受影响）。
- 修复：将 Storage.jsx / SelectField.jsx 用 `git checkout e3d81f8`（1.1.22）还原，再把"Enter 跳框 + 查重审查弹窗"两功能重新叠加到 1.1.22 版本（class 名保持 stg- 前缀不变）。
- 教训：改 class 名必须 JS 与 CSS 同步；下次若再看到"样式变了"，优先 `git show 3b0c8d9 -- app/src/index.css` 核实 CSS 是否改名。
- 版本 1.1.24 → 1.1.25，产物 `release-build/xingbao-warehouse-Setup-1.1.25.exe`。

## 环境注意：safe-delete shim 阻断 electron-builder / vite
- WorkBuddy 通过 `NODE_OPTIONS=--require=...genie-safe-delete.cjs` 注入回收站 shim，会把 Node 的 `fs.rm` 改为移入回收站，导致 vite 清空 dist 与 electron-builder 删除 `win-unpacked.tmp` 失败。
- 绕过：构建命令前加 `NODE_OPTIONS=""`（真实删除构建临时文件，属项目产物非个人文件）。Vite 构建前需先 `rm -rf dist`（否则 emptyOutDir 仍走 shim 报错）。
