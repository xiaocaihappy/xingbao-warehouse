## 第八轮：静态 IP 实际落地（踩坑修正）
- 用户直接在管理员 PowerShell 粘贴命令执行（绕过 .ps1 执行策略拦截 "禁止运行脚本"）。
- 防火墙命令（第一段）无报错 → TCP 3000 入站已放行。
- 第二段初版报错：① `New-NetIPAddress DefaultGateway already exists`（警告，不致命）；② `New-NetIPAddress` 报 **InvalidArgument / Error 87** —— 原因：关 DHCP 后旧地址没释放干净，同接口再塞同网段地址冲突。
- **修正命令**（已在用户机器跑通"可以了"）：
  ```powershell
  $idx = (Get-NetAdapter | Where-Object { $_.MacAddress -eq 'E0-D5-5E-9D-BB-92' }).ifIndex
  Set-NetIPInterface -InterfaceIndex $idx -Dhcp Disabled
  Get-NetIPAddress -InterfaceIndex $idx -AddressFamily IPv4 -ErrorAction SilentlyContinue | ForEach-Object { Remove-NetIPAddress -InterfaceIndex $idx -IPAddress $_.IPAddress -Confirm:$false }
  Start-Sleep -Seconds 2
  New-NetIPAddress -InterfaceIndex $idx -IPAddress 10.100.10.84 -PrefixLength 23 -DefaultGateway 10.100.11.254 -ErrorAction SilentlyContinue
  Set-DnsClientServerAddress -InterfaceIndex $idx -ServerAddresses 223.5.5.5
  ```
  - 关键点：先用 `Get-NetIPAddress` 把网卡上**所有 IPv4 逐个删干净** → `Start-Sleep 2` 释放 → 再写新地址；网关加 `-ErrorAction SilentlyContinue` 跳过"已存在"。
