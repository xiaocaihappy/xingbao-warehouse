# 2026-07-18 工作日志

## 修复：下拉菜单位置偏移 + Logo 光晕

### 问题1：下拉菜单位置偏移
- **根因**：CSS `.select-field-dropdown--portal` 中 `left: 0 !important; top: 0 !important;` 的 `!important` 覆盖了 React 内联样式的 `left/top` 值（由 `getBoundingClientRect()` 计算），导致下拉被强制固定在视口左上角
- **修复**：删除 CSS 中的 `left: 0 !important` 和 `top: 0 !important`，让内联 `style={{ top: dropdownPos.top, left: dropdownPos.left }}` 正常生效

### 问题2：Logo 背后青色光晕
- **根因**：`.sidebar-logo` 有 `filter: drop-shadow(0 0 12px rgba(0, 200, 255, 0.4))`
- **修复**：直接删除该 CSS 属性

### 文件改动
- `app/src/index.css`：两处修改（删除 logo drop-shadow + 删除 portal 的 left/top !important）
