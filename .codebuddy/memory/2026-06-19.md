## 修复：查询系统页面空白问题

### 根因分析
1. **Query.jsx 缺少错误处理**：`fetchItems` 或 `subscribeToItems` 抛出异常时，React 组件崩溃导致页面空白
2. **Supabase Realtime 发布未包含 `storage_items`**：`supabase_realtime` 发布列表为空，实时订阅失败

### 修改内容
| 文件 | 修改 |
|------|------|
| `Query.jsx` | 添加 `error` 状态 + try-catch 包裹 `loadItems` 和 `subscribeToItems` + `safeItems` 防御性检查 + 错误状态 UI（重试按钮） |
| `Dashboard.jsx` | `loadStats` 添加 try-catch + `subscribeToItems` 添加 try-catch |
| Supabase | `ALTER PUBLICATION supabase_realtime ADD TABLE storage_items` |

## 修复：左侧边栏页面滚动时固定不动

### 根因
`.dashboard` 使用 `min-height: 100vh`，内容超出一屏时整体滚动，侧边栏跟随滚动。

### 修改
`index.css` 两处改动：
1. `.dashboard`：`min-height: 100vh` → `height: 100vh; overflow: hidden;`（锁定视口高度）
2. `.sidebar`：添加 `position: sticky; top: 0; height: 100vh; overflow-y: auto;`（固定侧栏，内容过长时侧栏内自行滚动）
