## 2026-06-22 修复更新失败提示

### 问题
打包后的应用启动时右上角显示"⚠ 更新失败"。根因：`package.json` 中 `publish.url` 为占位域名 `xingbao-update.example.com`，启动后5秒后台静默检查时无法连接，错误消息触发 error 事件。

### 修复
- `updater.js`：
  - 新增 `_isSilent` 状态变量，标记当前是否为静默检查模式
  - `error` 事件：静默模式下 `sendStatus({ event: 'idle' })` 而非 error
  - `checking-for-update` / `update-not-available` 事件：静默模式下跳过或发 idle
  - `checkForUpdates(silent)`：在 try/finally 中维护 `_isSilent`
- `UpdateNotifier.jsx`：
  - idle 状态文字改为空字符串
  - idle 状态且无 message 时 render null（不显示按钮）
- 重新打包 ✅ `星堡移印仓储系统 Setup 1.0.0.exe`
