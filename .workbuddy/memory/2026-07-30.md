# 2026-07-30 工作记录

## 新增功能 (v1.1.26, 已打包+提交 3f80cf6)
四个需求全部实现，未改动任何已有 class/布局（仅新增 class）：
1. **存储系统切页输入保留**：`Storage.jsx` 用模块级 `storageFormDraft` + `formRef` + `justSavedRef`。卸载时存 form，重挂载恢复；成功保存后清空草稿。
2. **图片上传优化**：选/拖图 → `compressImage`（最长边 1600px JPEG 压缩提速）→ `ImageEditor` 裁剪旋转 → 后台异步上传（`useImageUploader`）。保存时 `awaitPending()` 等待在途上传，避免存半截图。预览区支持拖拽替换。
3. **图片编辑增强**：新增 `ImageEditor.jsx`（纯 Canvas，无依赖），支持 1:1 正方形 / 自由裁切 + 旋转（±90° 与滑块）。算法：先按未旋转坐标裁剪再整体旋转，与预览一致。
4. **查询系统编辑同步**：`Query.jsx` 编辑弹窗图片区接入同一套（拖拽 + ImageEditor + 后台上传 + 保存等待在途）。
